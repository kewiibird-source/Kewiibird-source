# 👋 안녕하세요! 방문해 주셔서 감사합니다.

사용자의 시선에서 고민하고, 서비스의 전체적인 흐름 속에서 문제를 해결하는 개발자 임예림입니다. 

단순히 코드를 작성하는 것을 넘어, 최적의 사용자 경험(UX)을 제공하는 것에 가치를 둡니다.

## 👩‍💻 About Me
* 서비스 제공자의 입장에서 사용자가 가장 직관적이고 편리하게 느낄 수 있는 화면과 기능을 기획하고 구현합니다.
* 문제에 부딪혔을 때, 지엽적인 부분에 갇히지 않고 프로젝트 전체의 흐름 속에서 원인을 찾고 근본적으로 해결하려 노력합니다.
* 백엔드부터 프론트엔드까지, 데이터가 화면에 그려지기까지의 일련의 과정을 즐기며 풀스택 개발 역량을 키워가고 있습니다.
